### 2순위. DSL 교차적합과 층화표본설계의 정합성 검증

<row align="center">
  <badge color="danger">최우선</badge>
  <caption>작업량: 중간 / 통계적 타당성 핵심</caption>
</row>

**현재 문제점**

현재 pseudo-outcome 수식은 고정된 보조 예측기에서는 설계기반 불편성을 설명할 수 있습니다.

그러나 실제 구현에서는 다음과 같이 예측 방법이 다릅니다.

- 라벨 표본: 5-fold out-of-fold 예측
- 비라벨 표본: 전체 라벨로 재학습한 모델의 예측
- 표본 추출: 층화 비복원 추출

이는 단순히 cross-fitting을 적용했다는 사실만으로 기존 DSL의 이론적 보장이 그대로 성립한다고 단정하기 어렵습니다.

Egami et al.의 DSL은 표본설계를 통제하고 참조 라벨을 이용하여 예측오차를 보정하는 접근입니다. 이론을 현재 연구의 표본 및 학습 구조에 적용하려면 해당 가정이 성립하는지 확인해야 합니다. <Cite refs={["turn180515search18","turn180515search23"]}/>

**최소 리소스 보완 방법**

기존 코드에서 아래 사항을 확인하십시오.

- 층별 표본 수와 교차적합 fold 배정 방식
- 학습 표본과 평가 표본의 분리
- 라벨 표본과 비라벨 표본에 적용된 예측기의 차이
- 교차적합에 사용한 포함확률의 적절성
- DSL 분산추정 시 층화 비복원 설계의 반영 여부

필요하다면 전체 모집단을 라벨과 무관하게 fold로 구분하고, fold 외부의 라벨만 학습에 사용하여 해당 fold의 모든 공고를 예측하는 방식을 검토하십시오. 이 경우에도 fold별 포함확률과 조건부 표본설계를 함께 정합화해야 합니다.

특히 아래 표현은 현재 상태에서 너무 강합니다.

> consistent and asymptotically normal whatever the accuracy of ĝ

**권장 문장**

> Under appropriate sampling and cross-fitting regularity conditions, DSL permits asymptotically valid inference without requiring a correctly specified auxiliary predictor.

그리고 현재 신뢰구간이 예측기 재학습의 불확실성을 완전히 반영하지 않는다는 점을 명시하십시오.

**분량 관리:** 기존 이론 설명을 교체하고, 상세한 fold 구성과 유도는 Supplementary S2로 이동합니다.

### 3순위. DSL 회귀 추정 불안정성의 직접적인 원인 규명

<row align="center">
  <badge color="danger">최우선</badge>
  <caption>작업량: 낮음~중간</caption>
</row>

**현재 문제점**

DSL 회귀 결과는 단순히 신뢰구간이 넓은 수준을 넘어 상당히 불안정합니다.

| 지표 | 현재 결과 |
|---|---:|
| 회귀계수 | -124.2%p |
| Sandwich SE | 1,812%p |
| Bootstrap CI | -495~429%p |
| Condition number | 3.05 × 10⁶ |
| 모의실험 95% CI coverage | 86% |

선형확률모형의 회귀계수가 100%p를 초과한다고 해서 그 자체로 구현 오류인 것은 아닙니다. 그러나 현재 결과는 추정량의 수치적·통계적 안정성을 추가로 점검해야 한다는 강한 신호입니다.

특히 condition number가 두 라벨 시나리오에서 동일하다는 사실만으로 고정효과 블록이 불안정성의 주요 원인이라고 결론 내리기는 어렵습니다.

**최소 리소스 보완 방법**

기존 회귀 행렬을 이용하여 다음의 세 가지를 계산하십시오.

1. 고정효과 블록만의 condition number
2. 전체 모멘트 행렬의 최소 고윳값과 양의 정부호 여부
3. AI 관련 변수의 유효 잔차 분산에 해당하는 Schur complement

\[
S=\hat A_{XX}-
\hat A_{XW}\hat A_{WW}^{-1}\hat A_{WX}
\]

\(S\)가 0에 가까워지면 AI 관련성 계수 추정이 극도로 불안정해질 수 있습니다.

추가로 기존 고정효과를 단계적으로 축소한 모형을 사후 진단용으로 비교하십시오.

| 모형 | 통제변수 |
|---|---|
| R0 | 절편만 |
| R1 | 국가 + 분기 |
| R2 | 국가 + 분기 + CPV |
| R3 | 기존 전체 통제변수 |

각 모형에서 회귀계수, SE, Schur complement를 비교하면 어느 부분에서 문제가 발생하는지 설명할 수 있습니다.

단, 더 좋은 결과가 나오는 모형으로 사전 지정 모형을 교체해서는 안 됩니다. 진단 목적의 사후 분석으로 유지해야 합니다.

**분량 관리:** 상세 결과는 Supplementary S3에 배치하고 기존 condition number 설명 문단을 교체합니다.

### 5순위. 희귀사건에 적합한 신뢰구간 검증

<row align="center">
  <badge color="danger">최우선</badge>
  <caption>작업량: 낮음~중간</caption>
</row>

**현재 문제점**

D층의 양성 건수가 4건에 불과하므로 일반적인 bootstrap percentile interval이 충분한 coverage를 제공하는지 불확실합니다.

D층 양성 표본 하나는 약 115건의 모집단 공고를 대표하므로 단순 표본 규모 1,199건보다 실제 희귀사건 정보량이 훨씬 작습니다.

또한 현재 원고는 다음 두 사실을 동시에 보고합니다.

- Bootstrap에서 모델을 재학습하지 않음
- 모의실험에서 95% sandwich interval coverage가 86%에 불과함

이는 95% 신뢰구간을 엄밀하게 해석하는 데 제약이 있습니다.

**최소 리소스 보완 방법**

HT 추정량의 층화 비복원 표본추출 분산을 직접 계산하십시오.

\[
\widehat{\mathrm{Var}}(\hat\theta_{\mathrm{HT}})
=
\sum_{h=1}^{H}
\left(\frac{N_h}{N}\right)^2
\left(1-\frac{n_h}{N_h}\right)
\frac{s_h^2}{n_h}
\]

이후 현재 bootstrap 결과와 비교합니다.

추가로 D층의 양성 건수에 대해 hypergeometric inversion 기반 구간을 검토하십시오. 구현이 어렵다면 층별 exact binomial interval을 이용한 보수적인 동시구간도 민감도 분석으로 활용할 수 있습니다.

DSL 및 회귀 추정에서는 가능하다면 기존 bootstrap 중 일부를 예측기까지 재적합하는 방식으로 수행하여, 고정 예측기 bootstrap과 비교하십시오. 단, 복제 가중치와 fold 구조는 실제 표본설계에 맞아야 합니다.

핵심은 bootstrap 반복 횟수를 2,000회에서 단순히 10,000회로 늘리는 것이 아닙니다. **신뢰구간 생성 방법의 적절성을 검증하는 것**입니다.

**분량 관리:** 구간 비교 결과를 Supplementary S4에 배치하고 본문에는 주요 결론의 유지 여부만 보고합니다.

- Secondary 결측 33건을 모두 양성 또는 음성으로 가정한 스트레스 테스트

| HT 양성 추정치 | Table 1의 반올림 합계 1,114건과 2.06%는 일치 |
| 회귀 표본 수 | 31,661−1,271−2 = 30,388로 일치 |
| D층 포함확률 | 정확히 450/51,756 사용 필요. 표의 0.009는 표시용 |
| D층 표본 가중치 | 약 115.01로 본문과 일치 |
| 라벨 비율 | 364/1,199의 비가중 양성 비율과 모집단 추정 비율 구분 필요 |
| M4 학습 방식 | 임계값을 라벨로 조정하면서 `requires no labels`라고 서술 |
| 언어 수 | TED 전체 24개 언어와 분석 프레임 23개 언어 구분 |
| H3 Union 결과 | 반올림 전 차이 확인 필요: 표시값 2.36−0.83은 1.53%p |
| LOO 분석 | 표본 제거인지 양성 라벨을 음성으로 변경한 것인지 확인 필요 |
| H4 판단 | `could not be assessed`보다 `was not supported; estimates were inconclusive`가 명확 |
| DSL 분산 설명 | prevalence와 regression에 대한 분산 추정 방법을 명시적으로 구분 |
| 문장 오류 | `one-sided bootstrap p-values`의 문장 시작 대문자 수정 |

특히 M4는 다음과 같이 수정해야 합니다.

> M3 is label-free, whereas M4 uses a label-free similarity score with a threshold selected within training folds.

추가로 **회귀 표본의 단일입찰 비율 46.2%**는 제공된 집계만으로 검산할 수 없으므로 원본 데이터와 대조해야 합니다.

### 12순위. DSL 보조 예측기 비교 및 분산 감소 검증

**현재 문제점**

M5의 분류 성능이 낮다는 사실만으로 DSL 보조 예측기로서 부적절하다고 판단할 수는 없습니다.

DSL의 핵심은 분류 임계값에서의 F1보다 모집단의 추론 대상과 관련된 예측잔차를 얼마나 줄이는가에 있기 때문입니다.

M5는 F1이 0.06이지만 사전 지정 모델 중 AUPRC는 0.33으로 가장 높았습니다.

반면 M5u는 F1을 개선했음에도 DSL prevalence 추정치는 1.31%로 낮아지고 신뢰구간은 더 넓어졌습니다.

**최소 리소스 보완 방법**

새로운 모델을 추가로 학습하기보다는 기존 예측확률을 재사용하여 비교하십시오.

| 보조 예측기 | 비교 목적 |
|---|---|
| 상수 0 | HT 기준선 |
| M1·M2 | 층 내부 상수 예측기 |
| M4 연속 유사도 또는 보정 점수 | 비지도 점수 활용 |
| M5 확률 | 기존 DSL |
| M6 확률 | 고전적 텍스트 분류기 |
| M5u 확률 | 비가중 학습 효과 |

각 조건에 대해 다음 지표를 계산합니다.

- DSL prevalence
- SE 및 95% CI
- 층별 예측잔차 분산
- HT 대비 분산 감소율
- 설계가중 Brier score

특히 D층의 잔차 분산을 보고하면 왜 DSL이 HT보다 정밀도를 개선하지 못했는지 직접 설명할 수 있습니다.

단, 가장 낮은 SE를 가진 모델을 사후 선택하여 confirmatory estimator로 교체하지 말아야 합니다.

**분량 관리:** 결과표는 Supplementary S7에 두고 Discussion에서 핵심 결과만 서술합니다.

### 13순위. 다중검정 및 가설검정 절차 명확화

**현재 문제점**

현재 H1–H3에 Holm 보정을 적용했다고 설명하지만, H2가 두 개의 하위 가설로 구성되므로 실제 검정 개수와 검정군을 정확하게 명시해야 합니다.

| 가설 | 검정 방향 | 현재 결과 |
|---|---|---|
| H1 | 단측 | 지지되지 않음 |
| H2a | 단측 | 지지되지 않음 |
| H2b | 단측 | 지지되지 않음 |
| H3 | 단측 | 지지됨 |
| H4 | 양측 | 불확실 |

**최소 리소스 보완 방법**

- Holm 보정에 포함되는 검정이 H1, H2a, H2b, H3의 총 4개인지 확인
- H4를 별도 검정군으로 둔 사전 계획상 근거 명시
- Bootstrap p-value의 계산식과 귀무가설 중심화 여부 확인
- 보고한 95% CI가 개별 구간인지 다중검정 보정 구간인지 명시
- 사후 분석에는 확증적 유의성 표현을 사용하지 않음

또한 M2가 가장 높은 관측 F1을 보였다는 것과 다른 모든 방법보다 통계적으로 우수하다는 것은 구분해야 합니다.

M2와 M1의 paired F1 difference에 대한 설계기반 bootstrap CI를 추가하면 다국어 사전의 실질적인 개선 효과를 더욱 명확하게 설명할 수 있습니다.

**분량 관리:** 검정 방법 한두 문장을 수정하고 상세 검정표를 Supplementary S8로 이동합니다.

### 14순위. 모델·데이터·참고문헌 재현성 점검

**현재 문제점**

재현성을 위한 정보는 충분히 많이 작성되어 있지만, 실제로 동일한 실험을 다시 실행할 수 있는 수준까지 정교화할 필요가 있습니다.

Claude Haiku 5.5의 모델명은 OpenRouter에서 확인됩니다. 다만 API 별칭과 날짜가 포함된 고정 버전 식별자가 구분되어 있으므로 실제 사용한 모델 ID를 로그와 대조해야 합니다. <Cite refs={["turn650693search3","turn650693search4"]}/>

| 구분 | 추가 확인 항목 |
|---|---|
| LLM | 실제 API model ID, provider, generation parameters |
| Hugging Face | 모델 repository ID 및 revision hash |
| Logistic regression | C, solver, max_iter, 가중치 정규화 여부 |
| 교차검증 | fold ID, seed, stratification 기준 |
| Dictionary | 전체 패턴, 정규식, 단어 경계 및 Unicode 처리 |
| TED | 실제 검색 쿼리, 검색일, 필드명, pagination |
| 표본 추출 | 모집단 프레임 해시, 표본 ID 및 seed |
| 사전 분석계획 | 기존 commit과 amendment의 변경 내역 |
| 참고문헌 | DOI, 저자명, 출판연도, 제목, 출판처 |
| 연구비용 | API 요청 수, 모델별 비용 및 재시도 수 |

추가로 다음 두 사항을 확인할 필요가 있습니다.

**첫째, 인용의 직접적인 적합성입니다.** AI 노출이나 채용공고 연구가 공공조달에서 영어 사전을 일반적으로 사용한다는 주장까지 직접 뒷받침하는 것은 아닙니다. 직접적인 공공조달 연구 또는 실제 AI 조달 추적기의 방법론 자료를 1~2개 보강하거나 주장의 범위를 좁히는 것이 좋습니다.

**둘째, 데이터 제공 방식입니다.** 원문을 배포하지 않는다면 공고 ID로 동일한 원문을 복원할 수 있는 데이터 수집 스크립트와 전처리 방법을 제공해야 합니다.

현재 GitHub 저장소의 실제 코드 실행 결과까지 검증한 것은 아니므로 재현성에 관한 최종 판단은 해당 저장소를 점검한 이후 가능합니다.

**분량 관리:** 상세 환경 정보를 `REPRODUCIBILITY.md`와 Supplementary S9로 이동하고, 본문에는 필수 실험 설정만 남깁니다.

### 6순위. Single-bidding 변수의 구성 타당성 검증

**현재 문제점**

TED의 입찰 건수는 공고 단위가 아니라 lot-result 단위로 기록될 수 있습니다. TED 공식 eForms 문서에서도 Received Submissions Count(BT-759-LotResult)는 lot-result 수준의 변수로 정의됩니다. <Cite refs={["turn180515search2","turn180515search3"]}/>

따라서 입찰 건수 필드가 하나만 존재하는 공고와 실제로 하나의 lot만 존재하는 공고는 구분해야 합니다.

또한 100건을 초과하는 입찰이나 입찰 건수가 0인 경우를 반드시 데이터 오류라고 볼 수는 없습니다.

**최소 리소스 보완 방법**

- 기존 XML 또는 JSON에서 lot 및 lot-result 식별자 확인
- 입찰 건수가 하나인 공고 중 실제 단일 lot 공고의 비율 산출
- 단일 lot 공고만 이용한 회귀분석 추가
- 100건 초과 표본을 포함한 민감도 분석 수행
- 0건의 제외 근거를 데이터 오류가 아닌 분석 대상의 정의와 연결

단일 lot 여부를 확인하기 어렵다면 결과변수 명칭을 다음과 같이 제한하는 것이 적절합니다.

> Notice-level indicator of a single reported tender count equal to one.

**분량 관리:** 변수 정의를 교체하고 강건성 분석을 Supplementary S5에 추가합니다.

### 8순위. LLM 라벨 변경 및 결측 처리 규칙 명확화

**현재 문제점**

현재 라벨 시나리오가 상당히 복잡합니다.

| 라벨 | 정의 | 양성 수 |
|---|---|---:|
| Primary | 첫 번째 LLM | 364 |
| Majority | 세 LLM 기반 부분 재판정 | 359 |
| Intersection | 두 LLM 모두 양성 | 336 |
| Union | 두 LLM 중 하나 이상 양성 | 374 |

하지만 두 번째 LLM의 라벨이 없는 33건은 primary label로 대체했으므로 Intersection과 Union이 엄밀한 의미에서 모든 표본에 대한 교집합과 합집합은 아닙니다.

또한 Majority는 세 번째 LLM이 1,199건 전체를 판정한 결과가 아니라 선정된 123건만 재판정한 결과입니다.

**최소 리소스 보완 방법**

- Majority를 `selectively adjudicated reference`로 명명
- Intersection과 Union에서 secondary label이 없는 경우의 처리 규칙 명시
- Secondary 결측 33건을 모두 양성 또는 음성으로 가정한 스트레스 테스트
- Primary 결측 1건의 양성·음성 가정에 따른 HT 및 DSL 추정치 비교
- 각 라벨 시나리오별 M5 재학습 여부 명시

특히 다음 문장은 논리적으로 정확하지 않습니다.

> hence the unparsed stratum-C notice cannot materially affect the estimates.

관측된 양성 하나를 제외하는 LOO 분석과 실제 결측 라벨의 영향을 분석하는 것은 동일하지 않습니다.

**권장 문장**

> Assigning the unresolved stratum-C label alternatively to zero and one provided a direct sensitivity check for primary-label nonresponse.

실제 분석 수행 후 결과에 맞게 기재하면 됩니다.

| ill-conditioning stems mainly from the sparse fixed-effect block | 고정효과 블록이 원인일 가능성이 있으나 추가 진단 필요 |
| captures roughly one third | estimated prevalence 대비 flag rate가 약 3분의 1 |

마지막 항목은 특히 중요합니다.

M1이 모집단 AI 관련 공고 비율의 약 3분의 1에 해당하는 수의 공고를 표시했다는 것과 실제 AI 관련 공고의 3분의 1을 찾아냈다는 것은 다릅니다.

M1의 관측된 recall은 0.28이며 precision은 0.69입니다. False positive도 존재하므로 단순 비율의 차이를 탐지율로 해석해서는 안 됩니다.

**권장 문장**

> The English dictionary flagged notices at approximately one third of the DSL-estimated prevalence.

이 수정은 Abstract, Results, Discussion, Conclusion에 일관되게 적용해야 합니다.

### 12순위. DSL 보조 예측기 비교 및 분산 감소 검증

**현재 문제점**

M5의 분류 성능이 낮다는 사실만으로 DSL 보조 예측기로서 부적절하다고 판단할 수는 없습니다.

DSL의 핵심은 분류 임계값에서의 F1보다 모집단의 추론 대상과 관련된 예측잔차를 얼마나 줄이는가에 있기 때문입니다.

M5는 F1이 0.06이지만 사전 지정 모델 중 AUPRC는 0.33으로 가장 높았습니다.

반면 M5u는 F1을 개선했음에도 DSL prevalence 추정치는 1.31%로 낮아지고 신뢰구간은 더 넓어졌습니다.

**최소 리소스 보완 방법**

새로운 모델을 추가로 학습하기보다는 기존 예측확률을 재사용하여 비교하십시오.

| 보조 예측기 | 비교 목적 |
|---|---|
| 상수 0 | HT 기준선 |
| M1·M2 | 층 내부 상수 예측기 |
| M4 연속 유사도 또는 보정 점수 | 비지도 점수 활용 |
| M5 확률 | 기존 DSL |
| M6 확률 | 고전적 텍스트 분류기 |
| M5u 확률 | 비가중 학습 효과 |

각 조건에 대해 다음 지표를 계산합니다.

- DSL prevalence
- SE 및 95% CI
- 층별 예측잔차 분산
- HT 대비 분산 감소율
- 설계가중 Brier score

특히 D층의 잔차 분산을 보고하면 왜 DSL이 HT보다 정밀도를 개선하지 못했는지 직접 설명할 수 있습니다.

### 13순위. 다중검정 및 가설검정 절차 명확화

**현재 문제점**

현재 H1–H3에 Holm 보정을 적용했다고 설명하지만, H2가 두 개의 하위 가설로 구성되므로 실제 검정 개수와 검정군을 정확하게 명시해야 합니다.

| 가설 | 검정 방향 | 현재 결과 |
|---|---|---|
| H1 | 단측 | 지지되지 않음 |
| H2a | 단측 | 지지되지 않음 |
| H2b | 단측 | 지지되지 않음 |
| H3 | 단측 | 지지됨 |
| H4 | 양측 | 불확실 |

**최소 리소스 보완 방법**

- Holm 보정에 포함되는 검정이 H1, H2a, H2b, H3의 총 4개인지 확인
- H4를 별도 검정군으로 둔 사전 계획상 근거 명시
- Bootstrap p-value의 계산식과 귀무가설 중심화 여부 확인
- 보고한 95% CI가 개별 구간인지 다중검정 보정 구간인지 명시
- 사후 분석에는 확증적 유의성 표현을 사용하지 않음

또한 M2가 가장 높은 관측 F1을 보였다는 것과 다른 모든 방법보다 통계적으로 우수하다는 것은 구분해야 합니다.

M2와 M1의 paired F1 difference에 대한 설계기반 bootstrap CI를 추가하면 다국어 사전의 실질적인 개선 효과를 더욱 명확하게 설명할 수 있습니다.

**분량 관리:** 검정 방법 한두 문장을 수정하고 상세 검정표를 Supplementary S8로 이동합니다.

\begin{abstract}
Studies of public-sector AI purchasing usually identify AI contracts with English keyword lists, but the error of this measurement in multilingual procurement data and its consequences for downstream estimates are seldom quantified. We compared scalable methods for identifying AI-related notices among 54,160 IT and software award notices published in Tenders Electronic Daily (TED) in 2024--2025, of which 6.1\% were in English. A stratified probability sample of 1,199 notices was annotated with a fixed codebook by a primary large language model (LLM) and checked against a second LLM (design-weighted $\kappa=0.77$); design-based supervised learning (DSL) was used to estimate prevalence and the association between AI-relatedness and single bidding under pre-specified hypotheses. A multilingual dictionary achieved the highest F1 (0.63, 95\% CI 0.50--0.78), doubling the recall of the English dictionary (0.56 vs.\ 0.28), whereas design-weighted embedding and TF-IDF classifiers performed worse (F1 0.06 and 0.10). The DSL prevalence was 2.32\% (CI 1.57--3.21\%), about three times the 0.83\% flagged by the English dictionary; the excess persisted, though smaller, under adjudicated labels. A naive regression suggested that AI-related notices were 4.9 percentage points less likely to report a single tender, but design-based estimates were too imprecise to determine the direction of any association. Keyword-based AI indicators in procurement therefore need multilingual terms and quantified measurement error before they are used for inference.\keywords{Public procurement \and AI-relatedness \and Multilingual text classification \and Design-based supervised learning \and Measurement error \and LLM annotation.}
\end{abstract}

\section{Introduction}
Public procurement is a principal channel through which governments acquire artificial intelligence (AI) systems and services, and the market for such contracts is of direct interest to suppliers, buyers, and regulators \cite{hickok2022}. Quantifying this market requires deciding which procurement notices concern AI. This decision is often operationalised with English keyword lists, as in studies that measure AI demand from online vacancies \cite{acemoglu2022,babina2024} and in public trackers of AI contracts. Keyword measures are transparent and cheap, but their accuracy is seldom reported against a reference annotation, and their error is rarely carried into the analyses that use them.

Two features of procurement data make this omission consequential. First, European notices published in Tenders Electronic Daily (TED) are written in 24 languages \cite{ahmia2018}; in the 54,160 IT and software award notices analysed here, only 6.1\% were published in English. An English dictionary may therefore miss AI purchases in a language-dependent way, which can distort cross-country comparisons. Second, an AI indicator produced by a dictionary or a classifier is often used as a regressor in a second-stage analysis. Recent work shows that plugging machine-generated variables into regressions can yield biased estimates and invalid confidence intervals unless the measurement error is addressed \cite{battaglia2025,egami2023}, and that correction methods differ in finite samples \cite{audinet2025}.

This paper examines how the measurement of AI-relatedness in procurement notices affects three quantities: classification accuracy, the estimated share of AI-related notices, and the estimated association between AI-relatedness and single bidding, a standard indicator of weak competition in procurement \cite{fazekas2016}. We compare six methods---two keyword dictionaries, a zero-shot natural language inference (NLI) classifier, an embedding-prototype score, and two supervised classifiers---against a codebook-based reference annotation of a stratified probability sample, and we apply design-based supervised learning (DSL) \cite{egami2023} to obtain prevalence and regression estimates that account for classifier error. Hypotheses, the sample design, and the codebook were fixed in an analysis plan before annotation. No human expert labels were available: the reference labels are produced by an LLM, checked against a second LLM, adjudicated post hoc by a third LLM where they matter most, and the influential cases are disclosed so that readers can judge them. The unit of analysis is the award notice; prevalence is a share of notices, not of contracts or of spending.

This study contributes (i) a design-based, language-stratified evaluation of AI-relatedness measurement in multilingual procurement notices; (ii) an assessment of how prevalence estimates depend on the text-based indicator and on a small number of contested reference labels; and (iii) an examination of how measurement uncertainty propagates into downstream estimates of procurement competition, including diagnostics that show when DSL regression becomes uninformative. Code, prompts, and notice-level derived data are released (see Data and code availability)
to support reuse in procurement monitoring. The contribution is methodological and empirical; no new learning algorithm is proposed.

\section{Related Work}
\subsubsection{Text-based measurement of AI demand.} Labour-economics studies identify AI demand through AI-related terms in job postings \cite{acemoglu2022,babina2024}, and large language models (LLMs) have been used to score occupational exposure to AI \cite{eloundou2024}. Text-as-data surveys emphasise that dictionary and supervised measures trade transparency against recall and that their error should be quantified \cite{gentzkow2019}. These studies mainly analyse English text and seldom report precision and recall against an independent annotation.

\subsubsection{Procurement analytics.} TED data support multilingual corpora \cite{ahmia2018} and national award databases \cite{potin2023}. Single bidding and related indicators are widely used to assess competition and integrity risk \cite{fazekas2016,decarolis2022}. Keyword screening is a natural way to locate technology purchases in such data, but we are not aware of work that quantifies its error across languages with a probability sample, or that traces this error into competition estimates.

\subsubsection{LLM annotation and inference with predicted variables.} LLMs can match or exceed crowd workers on several annotation tasks \cite{gilardi2023}, but performance varies widely across tasks \cite{ziems2024}, and agreement between LLMs does not establish accuracy because models can share errors. Prediction-powered inference (PPI) \cite{angelopoulos2023} and DSL \cite{egami2023} combine a small labelled sample with abundant predictions to obtain asymptotically valid estimates; benchmark evidence suggests that DSL often reduces bias more than PPI, although not uniformly \cite{audinet2025}. Multilingual sentence encoders \cite{wang2024me5,reimers2020} and NLI-based zero-shot classification \cite{yin2019,he2023} are alternatives to dictionaries whose performance varies by task and language \cite{muennighoff2023}.

\section{Method}
\subsection{Problem Formulation}
Let $i=1,\dots,N$ index award notices in the analysis frame (one TED publication number each) and let $X_i\in\{0,1\}$ denote AI-relatedness as defined by a fixed codebook. $X_i$ is observed only for a labelled subsample $\mathcal{L}$ drawn with known inclusion probabilities $\pi_i$; for every notice, a method $m$ produces a prediction $\hat{X}^m_i$ or a score. We target (a) the precision, recall, and F1 of each method relative to $X$, (b) the prevalence $\theta=N^{-1}\sum_i X_i$, and (c) the coefficient $\beta$ on $X_i$ in a model of single bidding $Y_i$ with controls $W_i$. The reference annotation defines the construct operationally; it is not treated as expert ground truth.

\subsection{Construct and Reference Annotation}
A notice is AI-related if the procured object includes the development, supply, licensing, operation, or consulting and training on a system whose core functionality relies on AI techniques (machine learning, deep learning, natural language processing or LLMs, chatbots, computer vision, speech recognition or synthesis, or predictive models learned from data). Generic software, workflow automation without AI, dashboards without learning components, and hardware are coded as not AI-related. This definition follows the task-based view of AI used in vacancy studies \cite{acemoglu2022} and the procurement-risk framing of AI systems \cite{hickok2022}. Each sampled notice was annotated by a primary LLM (Claude Haiku 5.5) and a secondary LLM (Gemini 2.5 Flash-Lite) with the same zero-shot prompt (temperature 0, JSON output). The pre-specified reference is the primary label $X$. Unparsable responses are treated as missing, never as negative. Agreement is reported as Cohen's $\kappa$, unweighted and design-weighted, together with positive and negative specific agreement. Two pre-specified variants require agreement of both annotators ($X_\wedge$) or either annotator ($X_\vee$). Post hoc, a third LLM (DeepSeek-Chat-v3.1) was given the same prompt and the majority of the three labels defines $X_{\mathrm{maj}}$. The third model labelled 123 notices: those whose first two labels disagreed or lacked a secondary label, plus all primary positives in strata C and D; when only two labels were available and they differed, the third label decided.
Because no human coders were available, this adjudication and the disclosure of all influential cases (Table~\ref{tab:cases}) replace expert validation; they do not make the labels ground truth.

\subsection{Measurement Methods}
\textbf{M1} applies an English AI dictionary (22 patterns, e.g., \textit{artificial intelligence}, \textit{machine learning}, \textit{chatbot}, \textit{LLM}) to every notice, mirroring common practice. \textbf{M2} adds core equivalents of \textit{artificial intelligence}, \textit{machine learning}, \textit{neural network}, \textit{language model}, and \textit{chatbot} in the EU languages and the abbreviations KI and IA. Because M1 and M2 define the sampling strata, both were fixed before sampling and annotation; their comparison contrasts two usable dictionaries, not a pure language effect, since M2 also differs in its term set. \textbf{M3} is zero-shot NLI with mDeBERTa-v3-base-mnli-xnli \cite{he2023,yin2019} and the hypothesis ``This procurement is about artificial intelligence'' (entailment probability $\ge 0.5$). \textbf{M4} is the maximum cosine similarity between a notice and five English prototype queries in the multilingual-e5-small space \cite{wang2024me5}, thresholded within training folds; its English prototypes make it not language-neutral. \textbf{M5}, the pre-specified embedding-based classifier, is an $L_2$-regularised logistic regression on multilingual-e5-small embeddings trained on the reference labels with weights $1/\pi_i$. \textbf{M6} replaces the embeddings with character 3--5-gram TF-IDF features, a strong classical baseline for short multilingual text. M3 and M4 require no labels. All label-trained components, including thresholds, are cross-fitted: predictions for labelled notices come from five folds that exclude them, which prevents optimistic evaluation and is required for DSL \cite{egami2023}. E5 inputs use the `passage:'/`query:' prefixes with mean pooling and $L_2$ normalisation; TF-IDF vocabularies are fitted within training folds, and unlabelled notices are scored by a model refitted on all labels.

\subsection{Sampling Design and Design-Based Estimation}
Because AI notices are rare, a simple random sample would contain few positives. The frame was partitioned into four strata: A (M1 hit), B (M2 hit but not M1), C (neither, but M4 similarity in the top 3\%), and D (remaining notices), and simple random samples were drawn without replacement within strata (seed 2027). Inclusion probabilities are $\pi_h=n_h/N_h$, where $n_h$ counts \emph{labelled} notices; in stratum C one of the 250 drawn notices received no parsable primary label, so $\pi_C$ is a nonresponse-adjusted probability that is valid if the failure is unrelated to $X$ within the stratum (Table~\ref{tab:design}). Accuracy metrics weight each labelled notice by $1/\pi_i$ and are therefore estimates for the whole frame. For prevalence and regression, DSL replaces the unobserved $X_i$ with the pseudo-outcome
\begin{equation}
\tilde{X}_i=\hat{g}(T_i)+\frac{R_i}{\pi_i}\bigl(X_i-\hat{g}(T_i)\bigr),
\label{eq:pseudo}
\end{equation}
where $\hat{g}$ is the cross-fitted M5 probability, $T_i$ the text, and $R_i$ the labelling indicator. For a fixed $\hat{g}$, $E_p(R_i)=\pi_i$ gives $E_p(\tilde{X}_i)=X_i$ under the sampling design; with cross-fitted $\hat{g}$, $\hat\theta_{\mathrm{DSL}}=N^{-1}\sum_i\tilde{X}_i$ is consistent and asymptotically normal whatever the accuracy of $\hat{g}$, which affects only its variance \cite{egami2023}. Finite-sample unbiasedness is not claimed. Setting $\hat{g}\equiv0$ yields the Horvitz--Thompson (HT) estimator. If $\hat{g}$ is constant within strata, as the M1 and M2 indicators are, $\hat\theta_{\mathrm{DSL}}$ reduces algebraically to $\hat\theta_{\mathrm{HT}}$; a predictor can therefore improve on HT only through within-stratum variation, chiefly in stratum D.

For the linear probability model $Y_i=\beta X_i+W_i^\top\gamma+\varepsilon_i$ on the regression sample $\mathcal{R}$ ($N_R$ notices), every OLS moment is linear in $X_i$ because $X_i^2=X_i$, so $\tilde{X}_i$ replaces $X_i$ wherever it appears:
\begin{equation}
\hat{A}=\frac{1}{N_R}\sum_{i\in\mathcal{R}}\begin{pmatrix}\tilde{X}_i & \tilde{X}_iW_i^\top\\ W_i\tilde{X}_i & W_iW_i^\top\end{pmatrix},\quad
\hat{b}=\frac{1}{N_R}\sum_{i\in\mathcal{R}}\begin{pmatrix}\tilde{X}_iY_i\\ W_iY_i\end{pmatrix},\quad
(\hat\beta,\hat\gamma^\top)^\top=\hat{A}^{-1}\hat{b}.
\label{eq:moments}
\end{equation}
The upper-left entry uses $\tilde{X}_i$, not $\tilde{X}_i^2$. Because $\tilde{X}_i$ can be negative or far above one, $\hat{A}$ is not guaranteed to be positive definite; we report its condition number. Labelled notices in $\mathcal{R}$ keep their frame inclusion probabilities. We report sandwich standard errors and stratified bootstrap intervals, and we checked the implementation on synthetic data with a known coefficient (Sect.~\ref{sec:reg}). A linear probability model is used because the specification contains over 100 fixed effects, for which logit estimates are less stable; logit plug-in estimates are a robustness check.

\section{Experimental Setup}
\subsection{Data}
We retrieved all TED contract award notices (eForms type \texttt{can-standard}) published between 1 January 2024 and 31 December 2025 whose CPV classification falls under IT services (72000000) or software packages (48000000), using the public TED Search API v3. TED notices may be reused for commercial and non-commercial purposes under the reuse policy of the European Commission. After deduplication by publication number (CPV matching includes additional CPV codes),
55,508 notices from 50 buyer countries in 23 languages remained; excluding notices with fewer than ten characters of title and description left an analysis frame of $N=54{,}160$, of which 3,308 (6.1\%) were in English. The text of a notice is its procedure title and description in its first official language (median 378 characters, truncated at 2,000). No personal data are used, and notice texts are not redistributed. An award notice can cover several lots or contracts, and a result notice does not guarantee that a contract was concluded, so notice shares should not be read as contract counts or market values.

Of the 54,160 frame notices, 17,864 report no received-tenders count, 4,635 report more than one (lot-level counts in multi-lot notices), and 31,661 report exactly one. Excluding counts of zero (1,271) and above 100 (2), implausible values also flagged in prior TED work \cite{potin2023}, leaves a regression sample of 30,388 notices, 630 of them labelled; 46.2\% received a single tender. A single reported count does not guarantee a single lot. The count is the eForms received-submissions value of type `tenders' (all tenders, not the SME or electronic sub-counts).
Controls are fixed effects for buyer country (absorbing institutional differences and the currency of the contract value), CPV division (26 levels after pooling divisions with fewer than 30 notices),
procedure type, buyer legal type, and publication quarter, plus log contract value with a missing-value indicator, following standard procurement-competition specifications \cite{fazekas2016,decarolis2022}.

\subsection{Sample, Annotation, and Implementation}
Table~\ref{tab:design} reports the sampling design. The 1,200 sampled notices were annotated by both LLMs through OpenRouter between 11:54 and 12:16 KST on 27 November 2026 (2,400 requests; total cost US\$0.14). One primary annotation (stratum C) could not be parsed, leaving 1,199 labelled notices, 364 of which were coded AI-related. The secondary model returned unparsable free text for 86 notices; re-querying them with the same prompt and an output limit of 120 tokens recovered 53, leaving 33 without a secondary label (17 in stratum D, 11 in B, 3 in A, 2 in C). The re-query and the adjudication (275 requests in total) cost US\$0.03.
On a shared 20-thread CPU (eight threads, no GPU), the dictionaries processed the frame in 7\,s (M1) and 20\,s (M2), multilingual-e5-small embedding took 1,229\,s (23\,ms per notice), and NLI took about 4\,s per notice. Bootstrap confidence intervals (CIs) use 2,000 resamples drawn with replacement within strata of the labelled sample; classifiers and thresholds are not refitted within replicates, so these CIs reflect label sampling only.
one-sided bootstrap $p$-values for H1--H3 are Holm-adjusted. Resampling with replacement ignores the finite-population correction, which is conservative for strata A and B; for prevalence it is immaterial, because the HT standard error is driven almost entirely by stratum D, where the sampling fraction is below 0.01.

\subsection{Pre-specified Hypotheses}
The analysis plan was fixed before annotation and committed to the project repository (commit 7314e8d, 27 November 2026, 11:12 KST; amendment commit b1eb797, 12:22 KST)
(a time-stamped repository commit, not an entry in an external registry). It stated: \textbf{H1} the recall of M1 is lower for non-English than for English notices, i.e., $\Delta_{\mathrm{H1}}=R_{\mathrm{non}}-R_{\mathrm{EN}}<0$; \textbf{H2} M5 attains higher F1 than M1 (H2a) and M2 (H2b); \textbf{H3} the DSL prevalence exceeds the M1 prevalence; and \textbf{H4} the DSL coefficient on AI-relatedness in the single-bidding model differs from zero (two-sided). One amendment, recorded before the affected results were computed, restricted M3 to the labelled sample because its projected CPU time for the frame exceeded the plan's six-hour rule; M3 is therefore evaluated for accuracy only. Analyses added after inspecting results, including the third-LLM adjudication, the re-query of failed secondary responses, and all leave-one-out analyses, are labelled post hoc.

\subsection{Classification Accuracy (H1, H2)}
Table~\ref{tab:acc} reports design-weighted accuracy. The multilingual dictionary (M2) achieved the highest F1 (0.63, 95\% CI 0.50--0.78), doubling the recall of the English dictionary (0.56 vs.\ 0.28) at similar observed precision (0.71 vs.\ 0.69); the precision difference was not tested. H1 was not supported under the primary reference: the recall of M1 was 0.25 for English and 0.28 for non-English notices ($\Delta_{\mathrm{H1}}=0.04$ from unrounded recalls, CI $-0.55$ to 0.27), largely because one English stratum-D positive carries a large weight. Zero-shot NLI (M3) was precise (0.96) but missed most AI-related notices (recall 0.11; F1 0.20). H2 was not supported, and the observed differences had the opposite sign: the pre-specified design-weighted classifiers M5 and M6 predicted almost no positives at the 0.5 threshold (recall 0.03 and 0.05; F1 0.06 and 0.10), although M5 had the highest threshold-free AUPRC among pre-specified methods (0.33). The F1 differences M5$-$M1 ($-0.34$, CI $-0.45$ to $-0.26$) and M5$-$M2 ($-0.57$, CI $-0.70$ to $-0.45$) were negative (Holm-adjusted $p=1.00$ for both one-sided tests). Post hoc, training M5 without design weights raised F1 from 0.06 to 0.36 at the fixed 0.5 threshold, and additionally tuning the threshold within folds gave 0.35 (M5u). The gain is therefore attributable to the training weights rather than to the threshold; the weighted model with a tuned threshold was not estimated, so the $2\times2$ comparison is incomplete.

\subsection{Prevalence (H3)}
The design-based estimates of the share of AI-related notices were 2.06\% (HT, labels only; SE 0.42 points; CI 1.38--2.94\%) and 2.32\% (DSL with M5; SE 0.42 points; CI 1.57--3.21\%). DSL with M5 therefore did not improve precision over HT; since the M1 and M2 indicators are constant within strata, using them as $\hat{g}$ would reproduce HT exactly. Naive shares were 0.83\% for M1, 1.62\% for M2, 6.51\% for M4, and below 0.2\% for M5 and M6. The DSL estimate exceeded the M1 share by 1.49 percentage points (CI 0.73--2.38; Holm-adjusted $p=0.002$), supporting H3: the English dictionary captures roughly one third of the estimated AI-related notices. The direction of this result held in every label scenario we examined (Table~\ref{tab:sens}), but its size did not.

\subsection{AI-Relatedness and Single Bidding (H4)}
\label{sec:reg}
Table~\ref{tab:reg} reports the linear probability coefficients. With naive plug-in indicators, the multilingual dictionary suggested that AI-related notices were 4.9 percentage points less likely to report a single tender (CI $-8.9$ to $-0.8$), whereas the English dictionary ($-1.7$, CI $-7.3$ to 3.9) and the other methods gave estimates whose CIs included zero. The labelled-only estimate was 3.1 points (CI $-8.0$ to 14.1; $n=630$). The pre-specified DSL estimate was uninformative ($\hat\beta=-124.2$ points, sandwich SE 1,812; bootstrap CI $-495$ to 429): the near-zero M5 probabilities for the heavily weighted stratum-D positives produce pseudo-outcomes far from $\{0,1\}$. The sandwich and bootstrap intervals differ greatly, itself a sign of instability. The precision tracks the number of stratum-D positives: with two of them ($X_{\mathrm{maj}}$) the SE fell to 177.2 points, and with one ($X_\wedge$) the coefficient was 6.0 points (CI $-6.7$ to 18.8). The condition number of $\hat{A}$ was $3.05\times10^{6}$ under both the primary and the majority reference; that it did not change with the pseudo-outcomes suggests that the ill-conditioning stems mainly from the sparse fixed-effect block rather than from $\tilde{X}$. In a synthetic check with a known coefficient of 0.10 and a deliberately miscalibrated predictor (200 replications), the estimator was close to the truth on average (mean 0.115, median 0.153) relative to its dispersion (mean SE 2.27), but 95\% sandwich intervals covered the truth in only 86\% of replications. We read this as evidence against a coding error in the point estimator and as a warning that sandwich intervals under-cover in this regime. The available estimates do not provide sufficiently precise evidence about the direction or magnitude of the association, so H4 could not be assessed.

\subsection{Robustness and Post hoc Analyses}

Table~\ref{tab:sens} summarises how the key estimates depend on the reference. Under the post hoc majority reference, M2 remained the best method, H1 remained unsupported ($\Delta_{\mathrm{H1}}=0.06$, CI $-0.61$ to 0.29), and the DSL prevalence fell to 1.84\%, still exceeding the M1 share (CI of the difference 0.38--1.83 points). Omitting a single stratum-D positive lowered the DSL prevalence from 2.32\% to 2.11\%, whereas omitting a stratum-C positive changed it only to 2.31\%; hence the unparsed stratum-C notice cannot materially affect the estimates. With the recovered secondary labels, the agreement reference $X_\wedge$ kept one stratum-D positive; it gave a DSL prevalence of 1.40\% (CI 1.09--1.91\%), the highest M2 F1 (0.73), and a lower recall of M1 for non-English than for English notices ($\Delta_{\mathrm{H1}}=-0.32$, CI $-0.61$ to $-0.06$); the union reference $X_\vee$ matched the primary analysis. A logit plug-in model reproduced the sign pattern of Table~\ref{tab:reg} (M2 odds ratio 0.77, SE of log-odds 0.11). M5u remained below M2 in F1 (difference $-0.28$, CI $-0.39$ to $-0.18$); using its probabilities in DSL gave a prevalence of 1.31\% (CI 0.37--2.36\%).

\section{Discussion}
\subsubsection{Measurement.} The confirmatory result that survives multiplicity correction is H3: an English keyword list identified about one third of the AI-related notices estimated from the design-based sample. Its direction was stable across reference definitions, but its magnitude depends on a handful of stratum-D labels (Table~\ref{tab:sens}). Adding core terms in the EU languages doubled recall at similar observed precision, so most of the gain came from handling language rather than from a more complex model. This is consistent with the multilingual composition of TED \cite{ahmia2018} and with the transparency--recall trade-off discussed for dictionary measures \cite{gentzkow2019}. The language-specific gap predicted by H1 appeared only under the agreement reference $X_\wedge$; under the primary and majority references it was masked by the uncertainty from a few heavily weighted positives. The large English--non-English recall gap of M4 is consistent with a language bias of its English prototypes, but our design cannot establish that cause.

\subsubsection{Why the supervised classifiers failed.} Contrary to H2, the embedding and TF-IDF classifiers underperformed the multilingual dictionary. Two features of the design explain this post hoc. First, training with inverse-probability weights gave each stratum-D notice a weight of about 115, whereas no notice in the dictionary strata had a weight above two ($\pi_h>0.5$), which pushed predicted probabilities towards zero; dropping the weights alone raised F1 from 0.06 to 0.36, and threshold tuning added nothing. Second, with 364 positives, most of which contain explicit AI terms, a linear classifier on general-purpose sentence embeddings learned little beyond the dictionary signal. These results do not show that supervised measurement is ineffective in general; they show that, at this label budget, weighting choices that are appropriate for estimation can be harmful for training, an implementation risk that is easy to overlook.

\subsubsection{Downstream inference.} The naive multilingual-dictionary regression produced a statistically significant negative association between AI-relatedness and single bidding, whereas design-based estimates were too imprecise to determine its direction. DSL gains precision over HT only when $\hat{g}$ predicts the rare positives within the low-probability stratum \cite{egami2023,audinet2025}; here M5 did not, so DSL matched HT for prevalence and became unstable for regression, where four contested labels determined much of the variance. The practical lesson is that a significant coefficient obtained with a keyword indicator should not be read as evidence about AI procurement when the measurement error has not been quantified \cite{battaglia2025}. For procurement monitoring, the results favour a multilingual dictionary for screening, combined with a labelled probability sample that devotes more of the budget to the unflagged mass, where most of the uncertainty lies.

%======================================================================
\section{Limitations}
The reference labels come from an LLM codebook annotation, not from expert coders. Agreement with a second LLM was moderate for English notices, and the third-LLM adjudication was post hoc; all three models may share errors, so the construct is ``AI-related according to this codebook and these annotators''. The nine disclosed cases show that prevalence conclusions depend on this choice. The label sensitivity analysis is not exhaustive. Bootstrap intervals ignore the finite-population correction, and sandwich intervals under-covered in our synthetic check. The frame covers only notices in two CPV divisions published in TED, i.e., mostly above EU thresholds, so AI purchases classified elsewhere or below thresholds are not observed, and notice shares are not contract counts or values. The regression excludes frame notices without exactly one valid tender count, which may introduce selection; a single count does not guarantee a single lot; and the controls omit buyer experience and supplier history, so omitted-variable bias is possible. All associations are non-causal. The dictionaries were written by the authors and may contain translation errors, and the stratification used M1, M2, and M4 scores, which makes the precision of estimates for other methods dependent on this design. Finally, a single small encoder and linear classifiers were tested, and the weight--threshold ablation was incomplete; fine-tuned or larger models may perform differently.

%======================================================================
\section{Conclusion}
We evaluated how AI-related public procurement notices are identified in 54,160 multilingual TED award notices, using a pre-specified stratified reference sample and design-based estimation. A multilingual dictionary roughly doubled the recall of the English keyword approach, and the English approach captured about one third of the estimated AI-related notices, a gap whose direction was robust to contested labels but whose size was not. An apparent negative association between AI-relatedness and single bidding under naive measurement could not be confirmed after accounting for measurement error. Future work should obtain expert-adjudicated labels, draw an additional probability sample from the unflagged stratum, complete the weight--threshold ablation, test fine-tuned multilingual classifiers, and extend the analysis to national systems such as the Korean KONEPS.
